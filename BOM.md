# Bill of materials

LanternLink deliberately reuses equipment already owned. Nothing was bought
for the build.

| Item | Quantity | Purpose | Added cost |
|---|---:|---|---:|
| Owned computer running macOS and Python 3.9+ | 1 | Signal sender | $0 |
| Owned computer running Windows and Python 3.9+ | 1 | Signal receiver and browser lantern | $0 |
| Existing private local network | 1 | Encrypted machine-to-machine path | $0 |
| Original LanternLink software | 1 | Signing, validation, replay defense, display | $0 |

The design also works with two suitable single-board computers. No particular
brand, cloud service, paid API, or special display is required.
